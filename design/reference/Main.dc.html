Writing

The way serious software gets built is changing. When a machine writes most of the code, the scarce input is judgment: what to build, how to model the domain, and how to keep a large system correct as it grows. I write about how large systems stay correct when AI writes the code, and about the architecture and data foundations that make AI useful.
